# MST QMS — 주식회사 엠에스티 품질경영시스템 소프트웨어

ISO 9001:2015 인증 범위(반도체 장비 부품 Chuck 생산)의 품질매뉴얼·프로세스·절차서·양식·KPI·내부심사·고객사(세메스 SSQ) 평가를 **한 프로그램에서 보고, 기록하고, 추적**합니다.
인터넷과 서버 없이 **Windows와 macOS에서 모두** 동작합니다.

기준 데이터는 Google Drive `MST` 폴더의 원본을 그대로 옮겼습니다.
- 품질매뉴얼 QM-01 Rev.01
- 프로세스맵 Rev.1
- 문서체계표 65행
- 절차서·지침서 47종
- 양식
- KPI 21개와 품질목표 4개
- 내부심사 체크시트 42문항·36문항
- 세메스 SSQ 45항목
- 교육자료 4과정

## 핵심: ISO 9001 ↔ 세메스 SSQ 연동
고객 평가 시트(세메스 SSQ 45항목)의 항목마다 아래 5가지를 한 줄로 묶었습니다. 메뉴는 **ISO ↔ 고객평가 연동**입니다.

1. 근거 ISO 조항
2. 기준 수립: MST 표준문서
3. 이행 실적: 양식·대장 기록 건수, 최근 작성일, 최근 3개월 중 기록이 있는 달 수
4. 같은 질문의 내부심사 판정
5. 최근 자체점검 점수

연동은 다음처럼 동작합니다.
- **내부심사 → SSQ:** 내부심사 체크시트 42문항은 SSQ와 1:1로 연결됩니다(SSQ 5·44·45 제외). 심사 화면의 **"SSQ 자체점검에 반영"**을 누르면 L=만점, M=절반, H=0점으로 자체점검이 만들어집니다.
- **ISO 조항 → SSQ:** 조항 화면에서 그 조항에 걸린 SSQ 항목과 현재 점수를 볼 수 있습니다.
- **SSQ → 기록:** 항목 상세에서 필요한 양식을 바로 작성할 수 있습니다.
- **체계 공백 10건 보완:** 원본에 없던 SSQ 요구사항을 신규 제정 권고 문서 2종과 양식 13종으로 넣었습니다. 상태는 "제정 예정"이고, 검토 후 승인하면 "문서 있음"으로 바뀝니다.
  - 클린룸·검사실 환경 지침 MI-0703
  - 정보보안·고객 도면 지침 MI-0810
  - Particle, 온·습도, 클린복, Air Utility, Jig 점검, 협력사 성적서·개선 대책, 외부문서(사업자등록증) 양식

## 로그인·권한
- 처음 실행하면 로그인 화면이 나옵니다. 사용자를 고르고 PIN(숫자 4–8자리)을 입력합니다. **처음 로그인할 때 입력한 PIN이 그 사람의 PIN이 됩니다.**
- 권한은 3단계입니다.
  - **관리자:** 전체 기능
  - **작성자:** 기록·대장·심사·부적합 작성
  - **열람:** 보기·검색·인쇄·CSV만
- 권한 변경과 PIN 초기화는 설정·백업에서 관리자만 할 수 있습니다.
- PIN은 누가 작성했는지 남기기 위한 장치입니다. 데이터 파일을 암호화하지는 않습니다.

## 원본 정정
Drive 원본을 옮기면서 300여 건을 고쳤습니다.
- 오타 259건
- 다른 회사 명칭·내용 30여 건 ((주)흥국, HK고객사, 프레스·코일 등)
- 타사 문서번호 12건 (HKB-, HKP-, QPF-)
- 표준 명칭 2건

전체 내역은 **문서 체계 → 원본 대비 수정** 화면에서 보고 CSV로 받을 수 있습니다. 구글 시트 원본에도 같은 수정을 반영하세요.

## 실행 방법

| 방법 | Windows | macOS | 특징 |
|---|---|---|---|
| **① 바로 실행** (설치 없음) | `MST_QMS_실행_Windows.bat` 더블클릭 | `MST_QMS_실행_Mac.command` 더블클릭 (처음 한 번은 우클릭 → 열기) | 기본 브라우저(Edge, Chrome, Safari)로 열립니다. 데이터는 그 PC의 그 브라우저에 저장됩니다. |
| **② 설치형 앱** (권장) | `MST-QMS-…-win-x64.exe` 설치 또는 portable 실행 | `MST-QMS-…-mac-universal.dmg` → 응용 프로그램으로 드래그 | 데이터가 **파일**로 저장됩니다(`문서/MST_QMS/mst-qms-data.json`). 공유폴더나 NAS를 지정할 수 있고 매일 자동으로 백업합니다. |

### 설치파일 만들기
- **GitHub에서 만들기:** 저장소 → Actions → **"MST QMS 설치파일 빌드"** → Run workflow를 누릅니다. 끝나면 Artifacts에서 `.exe`와 `.dmg`를 내려받습니다.
- **PC에서 직접 만들기:** Node.js 20 이상이 필요합니다.
  ```bash
  cd mst-qms
  npm install
  npm start            # 앱 실행
  npm run dist:win     # Windows 설치파일 (Windows PC에서)
  npm run dist:mac     # macOS dmg (Mac에서)
  npm run check        # 데이터·코드 점검
  ```
- macOS dmg는 코드 서명이 없습니다. 처음 열 때 **우클릭 → 열기**를 누르거나, 시스템 설정 → 개인정보 보호 및 보안에서 "확인 없이 열기"를 누르세요.

### 여러 PC에서 함께 쓰기
설치형 앱 → **설정·백업** → **공유 폴더 데이터 파일 지정**에서 회사 NAS나 공유폴더를 고릅니다. 네이버 MYBOX나 OneDrive 동기화 폴더도 됩니다. 모든 PC가 같은 파일을 가리키게 하면 됩니다.

같은 항목을 두 사람이 동시에 고치면 **나중에 저장한 내용이 남습니다**. 부서별로 담당 화면을 나눠 쓰세요.

## 참고 시스템(혜성고무 QMS 포털 V1)과 비교

| 구분 | 참고 포털 V1 | MST QMS |
|---|---|---|
| 실행 환경 | 사내 PC 1대에서 Node.js 서버를 돌리고 내부망으로 접속합니다. 서버 PC가 꺼지면 아무도 못 씁니다. | 각 PC에서 실행하는 앱 또는 브라우저 파일입니다. 서버가 필요 없습니다. |
| 기록(이행실적) | 양식을 내려받아 종이나 엑셀로 작성합니다. | **화면에서 직접 작성**하고 결재·사진·인쇄까지 합니다. |
| 업무 캘린더 | 주기별 목록만 있습니다. | 주기별로 **마지막 작성일을 보고 미작성·지연을 자동 판정**합니다. |
| 알림·할 일 | 없습니다. | 대시보드에 기한 초과·임박(부적합, 심사 지적, 교정, 설비 점검, 4M, 자격, 리스크)이 모입니다. |
| 부적합·시정조치 | 엑셀 대장입니다. | 6단계 워크플로를 관리하고 심사 지적·고객불만과 자동으로 연동합니다. |
| 경영검토 | 화면이 없습니다. | 입력사항을 자동으로 모으고 지시사항을 추적합니다. |
| 리스크·협력사·계측기·설비·교육·4M | 문서만 있습니다. | 각각 관리대장이 있고, 등급과 차기일을 자동으로 계산합니다. |

| 조항 충족도 | 없습니다. | 조항별로 실제 기록 건수를 세서 증거 충족률을 보여줍니다. |
| 고객 평가 | SQ 49항목을 자체평가합니다. | **세메스 SSQ 45항목**을 자체평가하고, 과락·추이·보완 과제까지 관리합니다. |
| 품질 도구 | 없습니다. | SPC 관리도·공정능력, MSA Gage R&R 계산기가 있습니다. |
| 교육 | 없습니다. | 계획·실적, 역량 매트릭스, 과정별 이해도 평가가 있습니다. |
| 백업 | 사람이 data 폴더를 복사합니다. | 앱이 매일 자동 백업(30일)하고, 수동 백업과 복원도 됩니다. |
| 고객 평가 연동 | SQ↔ISO 매핑표를 보여줍니다. | SSQ↔ISO↔문서↔**실제 기록 건수**↔내부심사 판정↔자체점검이 **자동으로 연동**됩니다. |
| 로그인·권한 | 공용 비밀번호 2개입니다. | 개인별 PIN 로그인, 관리자·작성자·열람 권한, 로그인 기록이 있습니다. |

## 한계와 다음 단계
- **로그인과 권한은 이 PC 안에서만 작동합니다.** 데이터 파일을 직접 열면 내용을 볼 수 있습니다. 강한 보안이 필요하면 서버형(예: 네이버 클라우드 + DB)으로 바꿔야 합니다.
- **동시 편집 충돌을 막지 못합니다.** 공유 파일 방식에서는 나중에 저장한 내용이 남습니다.
- **원본 데이터에 빈 부분이 있습니다.**
  - KPI 21개 중 20개는 목표값이 비어 있습니다. KPI 화면에 "목표 미설정"으로 표시됩니다.
  - 프로세스별 입력·출력은 원본에 없어서 [권장] 값으로 채웠습니다. 프로세스 오너가 확정해야 합니다.
- **[권장] 기준은 MST가 확정해야 합니다.**
  - 리스크 평가 기준(L×S)
  - 협력사 등급 기준(A≥90, B≥80, C≥70)
  - 내부심사 M 판정 점수(가중치×5)
- 원본 문서번호 충돌 때문에 고객만족 절차서를 임시로 **MD-0903**으로 두었습니다. 문서 체계 → 정합성 점검 4번 항목을 보세요.
