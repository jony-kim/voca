## 2. SPC (통계적 공정관리)

### 2.1 관리도 기본 [원문]
- 구성: CL(중심선), UCL/LCL(관리한계, ±3σ), USL/LSL(규격한계), 타점(Plot).
- **규격한계** = 고객·규제가 정한 합/부 판정 기준. **관리한계** = 공정 안정 여부(이상원인) 판정 기준. 둘은 혼용 금지.
- 3σ 관리한계 → 관리상태일 때 타점의 99.73%가 한계 내(1000점 중 약 3점 이탈).
- 변동 원인: 우연원인(공정 고유, 관리상태) vs 이상원인(조치 대상).
- 부분군: 동일 조건에서 무작위 추출, 군내는 우연원인만, 이상원인은 군간 변동에 나타나도록 구성.
- 계량형: X̄-R, X̄-S, Me-R, I-MR / 계수형: p·np(이항분포), c·u(푸아송분포).
- 해석용 관리도(기준값 없음, 데이터로 한계 산출) vs 관리용 관리도(기준값/목표값 주어짐).
- R = max − min. 실습 예: 부분군 n=3 → A2=1.023, D4=2.574 사용(슬라이드 명시).

### 2.4 공정능력 지수
[원문] 단기(Cp/Cpk) = 군내변동만, 최적조건, 데이터 30~50, 일·주 단위 / 장기(Pp/Ppk) = 군내+군간 변동, 일상조건, 데이터 100~200, 주·월 단위. Z = (USL(LSL) − μ)/σ. Z-shift ≈ 1.5σ (단기 6σ = 장기 4.5σ; 6σ ⇔ Cp=2.0, Ppk=1.5).

[표준값] 공식:
- Cp = (USL − LSL) / (6·σ_within), σ_within = R̄/d2 (또는 S̄/c4)
- Cpk = min[(USL − μ)/(3σ_within), (μ − LSL)/(3σ_within)]
- 한쪽 규격: Cpu = (USL − μ)/(3σ), Cpl = (μ − LSL)/(3σ)
- 치우침 k = |M − μ| / ((USL − LSL)/2), M = (USL+LSL)/2 → Cpk = (1 − k)·Cp
- Pp = (USL − LSL)/(6·s_overall), Ppk = min[(USL − μ)/(3s), (μ − LSL)/(3s)]
- 시그마 수준(단기) ≈ 3·Cpk (근사)

## 3. MSA (측정시스템 분석)

### 3.1 개념 [원문]
- 관찰 변동(TV) = 실제 공정 변동(PV) + 측정시스템 변동. σ²total = σ²part + σ²R&R.
- 정확도(위치): 편의(Bias), 선형성(Linearity), 안정성(Stability) / 정밀도(폭): 반복성(Repeatability, EV, 장비 변동), 재현성(Reproducibility, AV, 평가자 변동).
- 분해능: AIAG ≥ 공차 또는 공정변동의 1/10; ISO 기준 합부판정용 1/20(공차), 공정관리용 1/5(공정변동). %RE = RE/(USL−LSL)×100 또는 RE/6σtotal×100.

### 3.2 MSA 유형별 요약 [원문]
| 유형 | 내용 | 방법 | 판정 기준 |
|---|---|---|---|
| Type 1 | 반복성 & 편의 | 규격 중앙 기준시료 1개, 1명, 25회 이상(실무 50회) | Cg, Cgk ≥ 1.33 (AIAG: %EV=6s/TV×100, 편의 t검정 H0:bias=0) |
| Type 2 | Gage R&R(측정자 포함) | 부품 10개, 측정자 3명, 2~3회 랜덤 반복 | %기여 <1% 양호, %R&R(%연구변동) <10%, %P/T <10%, ndc ≥ 5 |
| Type 3 | Gage R&R(자동측정, 재현성 없음) | 부품 25개, 2~3회, 일원배치 변량모형 | Type 2와 동일 |
| Type 4 | 선형성 | 운영범위를 포함하는 부품 5개, 1명, 각 10회 이상 | 편의(Y)–기준값(X) 회귀: 기울기·절편 = 0 채택 시 합격, R² 기준(GM 95%) |
| Type 5 | 안정성 | 동일 표준시료를 기간별 3~5회 측정 | 해석용/관리용 X̄-R 관리도 관리상태 |
| Type 6 | 계수형 | 25개 부품(경계품 포함), 3명, 2~3회 | Kappa, 유효성, 누락률, 허위경보율 |

- Type 1 [원문+표준값]: Cg = (K/100·T)/(L·s) = 0.2·T/(6s); Cgk = (0.1·T − |x̄ − Xref|)/(3s) (K=20%, L=6 기본). 한쪽 규격: USL−4s 이하 / LSL+4s 이상이면 합격.
- 조치 [원문]: 반복성 > 재현성 → 계측기 보전·측정 위치 식별 / 재현성 > 반복성 → 교육·절차 표준화·눈금 조정.
- 파괴검사: 동일 로트 유사 시료로 대체(내포 Nested R&R). 측정자가 고정이면 혼합모형.

### 3.3 Gage R&R – 평균·범위법 (X̄-R 법) [표준값, AIAG MSA 4판]
- EV(반복성) = R̿ × K1
- AV(재현성) = √[(X̄diff × K2)² − EV²/(n·r)]  (음수면 0; n=부품 수, r=반복 수, X̄diff = 측정자 평균의 최대−최소)
- GRR = √(EV² + AV²)
- PV(부품변동) = Rp × K3  (Rp = 부품 평균의 범위)
- TV = √(GRR² + PV²)
- %EV = 100·EV/TV, %AV = 100·AV/TV, %GRR = 100·GRR/TV, %PV = 100·PV/TV
- 공차 대비: %GRR(tol) = 100 × 6·σGRR/(USL−LSL)  (여기서 EV 등은 σ 단위 사용 시 6배)
- ndc = 1.41 × (PV/GRR)  (소수 버림)

### 3.4 Gage R&R – ANOVA법 [표준값]
이원배치 변량모형(부품 p, 측정자 o, 반복 r):
- σ²반복성(EV) = MSE
- σ²교호작용 = (MS_OP − MSE)/r
- σ²측정자 = (MS_O − MS_OP)/(p·r)
- σ²부품 = (MS_P − MS_OP)/(o·r)
- σ²재현성 = σ²측정자 + σ²교호작용
- σ²GRR = σ²반복성 + σ²재현성, σ²Total = σ²GRR + σ²부품
- %기여 = 100·σ²GRR/σ²Total; %연구변동 = 100·σGRR/σTotal; %P/T = 100·6σGRR/(USL−LSL); ndc = 1.41·σpart/σGRR
- 교호작용 p값이 유의하지 않으면(일반적으로 α=0.05, Minitab은 α=0.05 기본; 슬라이드 예시는 "p>0.5 풀링") 교호작용을 오차에 풀링해 재분석.
- 음의 분산 추정치는 0으로 처리.

### 3.6 편의·선형성 기초 [표준값]
- 편의 = x̄ − 기준값; t = 편의 / (σr/√n), σr = 반복 측정 표준편차; 95% 신뢰구간에 0 포함 시 편의 허용. %편의 = |편의|/TV(또는 공정변동)×100.
- 선형성: 각 기준값 xi에서 편의 yi 계산 → y = a·x + b 회귀; 기울기 a·절편 b 모두 0이 유의하지 않으면(t 검정) 선형성 합격. 선형성 = |a| × 공정변동, %선형성 = 100·|a|.
- 안정성: 기준시료 주기 측정 X̄-R 관리도로 관리상태 확인.
- 측정 오차의 Cp 영향 [원문]: Cp(observed)는 실제보다 작게 나옴. Cp(obs)=1.5일 때 %R&R 10% → Cp(act) 1.51, 30% → 1.57, 50% → 1.73.

## 4. ISO 19011 심사 스킬

### 4.1 심사 원칙 [표준값 – ISO 19011:2018의 7원칙]
1. 성실성(Integrity) – 전문가로서의 기반
2. 공정한 보고(Fair presentation) – 진실하고 정확한 보고 의무
3. 전문가적 주의(Due professional care) – 근면과 판단
4. 기밀유지(Confidentiality) – 정보 보안
5. 독립성(Independence) – 공평성·객관성의 기반(자기 업무 심사 금지)
6. 증거기반 접근법(Evidence-based approach) – 검증 가능한 증거, 샘플링
7. 리스크기반 접근법(Risk-based approach) – 심사 계획·수행·보고에 리스크·기회 고려

### 4.2 심사 프로세스 단계 [원문 – MST 심사원 가이드 로직]
| 단계 | 핵심 활동 |
|---|---|
| ① 심사원 육성 | 분석적·개방적·경청 자세; 지식/숙련, 학력, 업무경험, 훈련/경험, 개인 특질 |
| ② 심사원 선정·팀 구성 | 독립성 확보, 심사경험·사리분별력·피심사자 친분 여부 고려, 객관성을 위해 2인 이상 |
| ③ 심사 계획 | 인원·기간·심사계획서·체크리스트 작성; 과거 부적합 조치 이력, 실수방지, 보증체계(고객불만·필드고장) 반영 |
| ④ 문서 검토 | 절차·지침·기록의 사전 검토 |
| ⑤ 시작회의 | 소개, 심사 범위·방법, 보고 방법, 심사 계획, 안내자 역할 확인 |
| ⑥ 현장 순회 | 시스템 '감' 잡기, 계획의 현실성 확인, 5S·설비/계측기 상태·제품 보관·안전 관찰 |
| ⑦ 현장 심사 | 점검표 활용, 피심사자 업무·절차 적용 시점·제품·공정·문서·기록 확인; 질문 → 확인 → 경청; 프로세스 접근(무엇·누가·어떻게·얼마나·입출력, 거북이 다이어그램) |
| ⑧ 심사팀 자체 회의 | 팀장 주관, 부적합 논의·근거 확보 확인, 부적합 진술 작성, 결과 요약 |
| ⑨ 종료 회의 | 심사 결과·결론 제공, 부적합/관찰사항 발표, 의견 공유, 시정조치 계획 합의 |
| ⑩ 보고서 작성 | 객관적 증거(요구사항·QMS 문서·규칙·고객/사내 요건·일반 상식) 기반, 추적 가능, 카테고리 분류, 피심사 조직 서명 |
| ⑪ 사후조치(시정조치) | 임시조치 → 근본원인 대책 → 수평전개 → 완료 확인(표준류 반영) → 유효성 확인 |

ISO 19011 공식 흐름(참고): 심사 개시 → 심사활동 준비 → 심사활동 수행 → 보고서 작성·배포 → 심사 완료 → 후속조치 수행.

시정조치 수평전개 대상 [원문]: QMS(사내 프로세스·절차·지침), 제품(도면 만족, 포장/라벨링), 공정(관리계획서·작업표준서·FMEA·체크시트).

### 4.3 부적합 등급 [원문 제목 + 표준 정의]
| 등급 | 정의 | 예 |
|---|---|---|
| 중부적합(Major) | 요구사항 전체가 누락·미실행되거나 시스템 붕괴, 부적합품 출하/고객 영향이 큰 경우, 동일 조항 경부적합 다수 반복 | 내부심사 미실시, 교정 미실시 계측기로 출하 판정 |
| 경부적합(Minor) | 시스템은 있으나 단발적·부분적 이탈로 효과성에 큰 영향 없음 | 일부 기록 승인 서명 누락 |
| 관찰사항(Observation/OFI) | 현재 부적합은 아니나 방치 시 부적합 가능성, 개선 권고 | 문서 개정 지연 우려 |

### 4.4 부적합 기술(Finding statement) 규칙 [원문: "형식: 요구사항 + (객관적 증거 + 부적합 사항)"]
구조:
1. **요구사항**: 근거 조항/문서 (예: "ISO 9001:2015 7.1.5.2 및 계측기관리절차 MST-QP-07은 측정장비의 정기 교정을 요구함")
2. **객관적 증거**: 확인한 사실 – 언제, 어디서, 무엇을(문서번호·LOT·장비번호), 누구 인터뷰 (예: "2026-09-10 가공1라인 마이크로미터 MM-012의 교정 유효기간이 2026-05-31로 만료됨")
3. **부적합 진술**: 요구사항과 증거의 차이를 간결히 (예: "교정 만료 계측기가 출하검사에 사용되고 있음")

작성 원칙: 사실 기반·검증 가능, 사람이 아닌 시스템 지적, 추측·의견 배제, 추적 가능(조항·문서번호), 피심사자 확인 서명, 등급·카테고리 분류.

### 4.5 심사원 역량 [원문 + 표준값]
- 개인 특성(19011 7.2.2): 윤리적, 열린 마음, 외교적, 관찰력, 지각력, 융통성, 끈기, 결단력, 자립성, 강인함(용기), 개선 지향, 문화적 감수성, 협력.
- 지식·스킬: 심사 원칙·절차·방법, 경영시스템 표준·참조문서, 조직 상황, 법규 요구사항, 분야별 기술 지식(제품·공정·SPC·MSA 등).
- 역량 평가 방법: 기록 검토, 피드백, 면담, 관찰, 시험, 심사 후 검토.
- MST 슬라이드 기준: 분석적·개방적·경청 / 지식·숙련, 학력, 업무경험, 훈련·심사경험, 특질.
- 독립성: 자기 부서 심사 금지 (ISO 9001 9.2.2 c 객관성·공평성).

## 5. ISO 9001:2008 vs 2015 주요 차이 [원문]

| 구분 | ISO 9001:2008 | ISO 9001:2015 |
|---|---|---|
| 구조 | 5개 주요 조항(4~8) | Annex SL(HLS) 10개 조항, 주요 조항 4~10 (타 경영시스템과 통합 용이) |
| 4장 | 품질경영시스템(일반·문서화) | 조직상황 – 내외부 이슈(4.1), 이해관계자(4.2), 적용범위(4.3) 신설 |
| 리더십 | 경영자 책임, 경영대리인 지정 | 리더십·책무, 비즈니스 프로세스와 통합, **경영대리인 삭제** |
| 리스크 | 예방조치(8.5.3) | **리스크기반 사고(6.1)**, 예방조치 조항 삭제 |
| 문서 | 문서/품질매뉴얼/문서화된 절차(6개)/기록 | **문서화된 정보**로 통합: 유지(maintain)=문서, 보유(retain)=기록; 매뉴얼 필수 아님 |
| 적용 제외 | 7장에 한해 제외 가능(1.2) | "제외" 용어 삭제, 모든 조항에 적용가능성 판단 + 정당성 제시(4.3, A.5) |
| 제품 | "제품"(서비스는 제품의 일종) | "제품 및 서비스" |
| 구매 | 구매(7.4), 공급자 | 외부에서 제공되는 프로세스·제품·서비스(8.4), 외부공급자 |
| 업무환경 | 업무환경(6.4) | 프로세스 운용 환경(7.1.4, 사회적·심리적 요인 포함) |
| 측정장비 | 모니터링·측정 장비 관리(7.6) | 모니터링·측정 **자원**(7.1.5) |
| 신규 요구 | — | 조직의 지식(7.1.6), 변경의 기획(6.3), 변경관리(8.5.6), 인적오류 방지(8.5.1 g), 인도 후 활동(8.5.5) |
| 제품실현 | 7장 제품실현 | 8장 운용 |
| 측정·분석·개선 | 8장 | 9장 성과평가 + 10장 개선 분리 |
