### 2.0.1 평가 척도 / 컬럼 (공통)
- 머리부: 심사 일자 / 심사 장소 / 심사 담당 (공란), 제목 "품질경영시스템 내부심사 체크시트"
- RISK 등급 정의 (적합/부적합/관찰 방식이 아닌 **H/M/L 3단계 RISK**):
  - **H**: 관련 프로세스가 절차서/지침서에 따라 수행되지 않으며, 동일누락 또는 오류가 많음
  - **M**: 관련 프로세스가 절차서/지침서에 따라 수행되고 있으나, 일부 항목의 누락 또는 오류가 있음.
  - **L**: 관련 프로세스가 절차서/지침서에 준하여 누락 또는 오류 없이 수행됨.

### 3.4 MST_측정시스템 분석 (MSA)
https://drive.google.com/file/d/1QdQ28n2MMmy3eVetmP1LA0caYuCjf7mQ/view
- 모듈 1 측정 시스템 이해: 관찰된 공정 변동 = 실제 공정 변동(장기/단기) + 측정시스템 변동. 측정시스템 변동 = 계측기에 의한 변동(반복성 Repeatability, EV) + 측정자에 의한 변동(재현성 Reproducibility, AV). 위치변동: 편의(Bias), 안정성(Stability), 선형성(Linearity) / 너비변동: 반복성, 재현성. PV, TV.
- 모듈 2 [개요] 주요 공식 (표):

| 구분 | 항목 | 공식 / 평가 기준 | 평가 준비 | 전제 |
|---|---|---|---|---|
| Type #1 | 반복성(편의) | %EV=6s/TV*100, 10% 미만 합격; 편의 T-test H0[치우침]=0 기각 | 규격 중앙값에 해당하는 1개 부품 | 해당 규격을 갖은 제품의 측정 능력 |
| Type #2 | 반복·재현성 | %기여=[σ²R&R/σ²total]*100 1% 미만 합격; %R&R=[σR&R/σtotal]*100 10% 미만 합격; %PTR=[6σR&R/(USL-LSL)]*100 10% 미만 합격; Ndc=1.41*[σp/σR&R] 5 이상 합격 | 10개 부품, 3명, 2~3회 반복 | 장비와 측정자간의 계측기 시스템에 영향을 주는지 파악, 분산 분석을 통한 부품과 측정자 간의 교호작용 검증 |
| Type #3 | 반복성 | Type 2 기준과 동일 | 랜덤 취출 25개, 2~3회 | 측정자의 영향이 없는 경우, 자동 측정 장비 |
| Type #4 | 선형성 | R² 95% 이상(GM); H0:기울기(a)=0, H0:절편(b)=0, H0 채택시 합격 | 계측기의 운영범위를 포함하는 부품 5개, 1명, 10회 이상 | 제품 공차 내 범위간 측정시스템 산포 |
| Type #5 | 안정성 | 해석용·관리용 관리도 규격 내 만족(xbar-R) | 동일 부품, 시간 간격, 3~5회 | 주변 환경에 따른 측정시스템 산포 |
| Type #6 | 적합성 평가(계수형) | Kappa 계수 만족 이후, 인원간 측정시스템 분석 | 25개 부품(매어 20%, 어 30%, 약쉬 30, 매쉬 20%), 3명, 2~3회 | — |

- 모듈 3 일반: 의사 결정의 진화 단계(1단계 경험 / 2단계 경험+지식 / 3단계 경험+지식+데이터), "대부분의 의사결정이 데이터에 근거 하므로 데이터의 품질이 중요하다."
- 측정시스템 평가 단계 1·2·3 (단계 3: 평가자 수·시료수·반복 횟수 결정, 판별력 공정변동 대비 1/10, 시방서 적합여부는 공차대비 %GRR, 공정변동 관리는 공정변동 대비 %GRR)
- 측정의 정의, 측정 총변동 σ²total = σ²p + σ²R&R, 측정시스템 변동이 공정능력지수·불량률에 미치는 영향
- 용어: Gage R&R, 정확도(편의·선형성·안정성) vs 정밀도(반복성·재현성), 편의/반복성(EV)/선형성/안정성/재현성(AV) 정의

- Type 1 Study: Cg, Cgk ≥ 1.33 합격 / Type 2: Gage R&R, 10개 시료, 3명, 랜덤 2~3회 / Type 3: 자동측정장비, 일원배치법 변량 모형 / Type 4: 선형성 회귀 / Type 5: 안정성, 기간마다 표준시료 3~5회 / Type 6: 계수형(Go/No gage, 관능검사) — 측정 일관성·정확성·일치성, 규격 밖 시료 포함, GPC 작성.

### 6.4 자체평가 모듈 설계용 정리 (원문 기반, 해석은 [주])
- 채점 단위: 항목별 배점(1·2·3·4점) 안에서 단계 점수 선택. 단계는 항목마다 다름(예: 3/2/1/0, 3/1.5/0, 2/1/0, 1/0.5/0). 감점형(28번: 위반 1건당 0.5 감점), 가산형(27번: 5S 항목당 0.2, 35번: 1+0.5×4), 비율 적용(19번: 일정 미도래 시 50%, 35번: 전용 검사실 없으면 50% 반영) 규칙이 섞여 있음.
- 연쇄 규칙: 18·19번 "검사 실적(현황) 미 관리시 0점"이 10·16번 결과에 연동됨. 38·39번 "1ea 교정 누락시 0점".
- 과락: 44, 45번 중 하나라도 해당하면 과락(총점과 무관).
- 총점 = Σ 항목 점수 (만점 100, [주] 계산값). 등급 구간과 합격 점수 기준은 원문에 없으므로 확정 필요.
- 내부 체크시트(2.A) ↔ SSQ 번호 대응: 내부 1.1~1.4 = SSQ 1~4, 내부 2.1~2.11 = SSQ 6~16, 3.x = 17~19, 4.x = 20~21, 5.x = 22~24, 6.x = 25~30, 7.x = 31~35, 8.x = 36~43. 내부 시트에 없는 것: SSQ 5, 44, 45.
