# 참고 시스템 기능 인벤토리 — (주)혜성고무 「품질경영시스템 포털 V1」 (+ 동종업계 MES 사례)

> 작성 근거 (2026-10-05 조사)
> - `8. 시스템(포털)` 폴더: 「설치 및 사용 안내」(Google Doc) + `혜성고무_QMS포털_V1_설치파일.zip`(168 MB)
>   - **zip 원본은 열지 못함**: Drive MCP 다운로드 한도 10 MB 초과, 직접 다운로드(drive.usercontent.google.com)는 이 환경의 egress 프록시에서 차단됨. 따라서 **소스코드(HTML/JS/서버) 직접 분석은 못 했음.**
>   - 대신 `7. 완료 보고` PDF(31쪽)에 들어 있는 **포털 실화면 캡처 12장 + MES 사례 캡처 10장**을 추출해 화면 단위로 판독했고, 포털이 읽는 원천 데이터인 **엑셀 3종(문서체계표·KPI·내부심사)의 시트/컬럼**을 직접 열어 확인함.
> - **중요 정정**: 이 포털은 **네이버 클라우드 배포가 아님**. 「사내 PC 1대 = 서버」로 설치하는 **Node.js 로컬 웹서버(포트 8080), 사내망 전용** 구조임. 완료보고서 26~30쪽의 어두운 사이드바 「MES」 화면은 "동종 업계 적용 사례(업체명 비공개)"로 소개된 **별개 시스템**이며, 클라우드로 운영되는 시스템이 있다면 이쪽일 가능성이 높음(아래 §3-B에 별도 정리).

## 3-A. 화면별 기능 상세 (포털 V1)

### ① 홈
- 헤더: 회사명, 적용규격·문서버전(V1, 2026-09-22)
- 요약 카드 3: 표준문서 52 / 양식 162(신규 90) / SQ 1,000점 만점(해당없음 50점 제외 950점 대비 환산)
- 회사정보 바: 대표자·사업자번호·소재지·업태·종목·전화
- 바로가기 카드 6: 품질매뉴얼, 프로세스·절차·지침·양식, 프로세스맵·문서체계도, KPI(140·월실적·추이), 내부심사(120+49), 조직·부서별 업무(5개 부서)
- **「이행실적(기록) 즉시 착수 대상」 표**: 양식번호 | 양식명 | 관련 SQ(칩) | 작성 부서 — 우선 착수 양식 12종(자주검사 체크시트(CAVITY별), 순회검사 기록표, 2차 가류 일지, 공정이동전표, 금형 일상점검, 금형 세척 관리대장, 숙성실 온습도, 접착제 도포 검증, 안전점검 2인1조 …). 문구: "SQ는 기준(문서)과 이행실적(기록)을 분리 채점 → 최소 3개월 연속 기록 확보"
- 완료보고서 설명상 "이번 달 할 일"도 표시

### ② 품질매뉴얼 (QM-01)
- 엑셀판(조항별 본문·KPI) + PPT판(49쪽) 열람·다운로드. 표지/품질방침/조직도/프로세스MAP 포함

### ③ 프로세스·절차·지침·양식 → 문서 상세 화면 (예: MD-0814 금형관리 절차서)
- 제목 + 배지(신규 / Rev.0), 브레드크럼
- 메타: 유형, ISO 조항, 주관부서(링크), 상위 프로세스(링크), 목적, 적용범위
- 버튼: **미리보기 / 다운로드**
- 우측 **성과지표(KPI)** 카드: 지표명(링크) | 목표 | 주기
- **업무 흐름(PDCA) 카드 6열**: PLAN / DO / DO / CHECK / ACTION / ACTION — 각 단계 활동 bullet, 담당부서, 관련 양식번호 링크. 버튼 **현장 게시용 PDF / PPT**
- **소속 양식(기록물) N종 표**: 양식번호 | 양식명 | 구분(신규/보유) | 연계 SQ | 다운로드
- (완료보고서) 개정 이력, 관련 문서 바로가기도 같은 화면

### ④ 양식 미리보기 (예: MD-0814-003)
- 버튼: ← 문서 정보 / 원본 다운로드 / 새 창
- PDF 뷰어 임베드(페이지·확대·인쇄·다운로드)
- 양식 표준 헤더: 로고, 회사명+양식명, **결재란(작성/검토/승인)**, 양식번호, 개정번호, 주관부서, 작성주기, 보존기간, 연계 SQ → 본문 기록 표
- ※ 포털은 **양식을 "보여주고 내려받게"만 함. 화면 입력/전자기록 아님**

### ⑤ 프로세스맵·문서체계도 (4탭)
- **프로세스 맵**: MP/COP/SP 구조 그림
- **문서체계도**: 안내문 "QM → MP → MD → MI → 양식(문서번호-3자리), CC=ISO 조항(04~10), nn=일련번호". 표: 구분(MP/COP/SP 칩) | 프로세스(번호·명) | 오너 | 절차서 | 소속 양식 | 지침서 | 소속 양식 — 모든 번호 링크
- **프로세스 상호관계**: 프로세스×프로세스 ◎ 매트릭스
- **SQ↔ISO 매핑표**: 영역 드롭다운 + 텍스트 필터. 컬럼: SQ | 영역 | 평가항목 | 배점 | 적용(적용/해당없음, 해당없음은 회색) | 주관 표준문서·조항 | 필요 기록물(양식번호 링크)
- **SQ 항목 상세**(예: SQ 4_2): 영역, 배점, 적용, 주관 문서·조항, 필요 기록물(링크), 관련 표준문서. (완료보고서: 평가기준·점검 포인트 포함)

### ⑥ KPI 성과지표 ("월 1회 집계 → 경영검토 보고 [SQ 6_7]")
- 카드 4: 등록 성과지표 140 / 해당연도 실적 입력 지표 수 / 월별 목표 달성률(입력분 기준) / **목표값 [확인필요] 지표 수(17)**
- 필터: 연도 선택, 부서 칩(전체·관리부 42·생산부 28·영업부 13·품질부 46·연구전담 11)
- 핵심 지표 **꺾은선 차트**(1~12월, 목표선 점선): 고객 불량 PPM, 공정 불량률, 납기 준수율, SQ 자체평가 점수
- 표(문서 그룹별, 예 "전사(품질매뉴얼) 4"): 성과지표(링크) + 문서번호·산출식 | 목표 | 부서 | 주기 | **1~12월 입력칸** | 달성
- 관리자만 입력 → 플로팅 **「실적 저장」** → kpi_actuals.json
- 원천 엑셀 컬럼: 구분 | 표준문서 | 성과지표 | 산출식 | 목표 | 주관부서 | 측정방법 | 주기(매월 75·분기 28·반기 12·연 …)
- 미달 시 대책은 화면 기능 없음(운영규칙상 MD-1001 개선활동 등록으로 안내만)

### ⑦ 내부심사 (ISO 9001 + SQ Ver5.1 고무성형)
- 헤더 입력: 심사일(date), 심사원, 피심사부서 / 버튼 **체크시트 엑셀 원본**, **심사 결과 저장**
- 탭1 **ISO 9001 체크시트(120)**: 분류별 그룹(품질경영·공정관리·검사관리·자재·부적합·계측기·설비·교육훈련·안전·변경점·인프라·금형·협력사). 문항마다 No·**가중치**, 질문, 근거(문서·조항), 증빙(양식), 책임, 연계 SQ 칩, **판정 버튼 양호(L)/보완(M)/미흡(H)/해당없음**, **점검 결과(5W1H) 텍스트**
  - 점수식: RISK L=10·M=5·H=0, 문항점수 = 가중치×RISK → "현재 x / 1310점 (%)" 실시간 집계
- 탭2 **SQ 자체평가(49)**: 항목·영역·평가항목·배점·적용·점검포인트·확인문서·확인기록·책임부서·**기준수립 등급 / 이행실적 등급**(우수1.0·양호0.8·보완0.6·일부미흡0.4·다수미흡0.2·미관리0) → 자체 평가점수(1,000점 환산)
- 탭3 **결과 요약·지적사항**: 점수·부적합 자동 집계. 원천 엑셀의 「지적사항 및 개선대책 관리대장」 컬럼: 발행번호 | 심사구분(ISO/SQ/고객) | 심사일자 | 해당 항목 | 지적 유형(기준수립/이행실적) | 지적 내용 | 등급 | 원인 | 개선대책(응급/근본/수평전개) | 담당 | 완료기한 | 완료일 | 유효성 확인 | 확인자
- 저장 → audit_results.json (심사 회차 이력 관리 수준은 불명)

### ⑧ 업무 운영 캘린더 ("누가, 언제, 어떤 양식으로")
- 부서 필터 칩 / 버튼 **현장 게시용 흐름도 모음(PDF) / PPT**
- **운영 규칙 4카드**: 1.문서 개정(요청→주관부서 초안→품질부 검토→대표 승인→문서체계표·표준목록·양식마스터 동시 갱신→구본 회수·현장게시본 교체) 2.기록 작성(최신본 다운로드→실측값 기재→부서장 확인→보존기간 보관) 3.월간 점검(매월 첫 주 KPI 입력→미달 시 MD-1001→경영검토) 4.내부심사(연1회 이상, 지적→시정조치 요구서→완료 1개월 후 유효성 확인)
- 주기별 섹션(매 작업 시 / 교대 시 / 일 / 주 / 월 / 분기 / 연 …): 양식번호 | 기록(양식)명 + 배지(신규·**즉시 착수**) | 근거 문서 | 작성 부서 | 연계 SQ | **양식 받기**
- ※ 실제 "달력(날짜 그리드)"이 아니라 **주기별 리스트**이며, 작성 여부 체크/누락 알림 없음

### ⑨ 조직·부서별 업무
- 조직도(대표이사 → 이사 → 5개 부서 카드: 부서장, 담당업무 bullet, "프로세스 n · 문서 n · KPI n"), 부서 클릭 시 해당 부서 절차서·기록·KPI 필터
- **부서별 책임 매트릭스(주관● / 협조○)**: 프로세스 × 부서
- 출처: MD-0501-001 조직도, MD-0501 업무분장표

### ⑩ 신규 제정 ("번호 자동 부여 → 문서체계 즉시 반영 → 정합성 자동 검증")
- 입력: 종류(프로세스/절차서/지침서/양식), 소속 표준문서(드롭다운), **자동 부여 번호 표시(예 MD-0501-003)**, 문서명, 주관부서, 관련 SQ 항목, 작성주기(양식), 작성자, 제정 사유, 문서 파일 업로드 → **신규 제정 등록**

## 6. 강점 / 약점·한계 (QMS 전문가 관점 평가)

### 강점
1. **문서체계 중심 설계가 매우 정교함**: 프로세스→절차→지침→양식→SQ→KPI가 번호로 완전 연결, 어느 지점에서 들어가도 상·하위로 이동 가능. SQ "기준수립 vs 이행실적" 분리 채점 철학이 화면 전반에 반영.
2. **정합성 자동 검증**: 문서 개정 후 끊어진 참조·누락 파일을 잡아줌 → 심사 전 문서 품질 확보에 실효적.
3. **채번 규칙 내장**: 신규 제정 시 번호 자동 부여, 파일명 규칙 강제.
4. **내부심사 체크시트 디지털화**: ISO 120 + SQ 49 동시 판정, 점수 실시간, 5W1H 기록.
5. **설치/운영비 0, 데이터 회사 소유**, 학습 부담 적은 UI, 현장 게시물(흐름도 40종) 연계.

### 약점·한계
1. **사실상 "문서 열람 포털"** — 기록(이행실적)은 여전히 **양식 다운로드 → 종이/엑셀 작성**. SQ에서 실제 점수를 좌우하는 "3개월 연속 기록"을 시스템이 보장·집계하지 못함. 기록 누락 탐지 불가.
2. **보안·권한 취약**: 공용 비밀번호 2개, 개인 식별 없음 → 누가 입력/승인했는지 **감사추적(audit trail) 불가**. ISO 7.5.3(문서화된 정보의 관리: 접근·변경관리)·IATF 전자기록 요구에 약함. 전자서명/결재 없음.
3. **인프라 리스크**: 사내 PC 1대가 서버 — PC 꺼짐/고장/랜섬웨어 시 전체 중단, **백업 수동**, 외부·모바일(현장 4G) 접속 불가, 동시편집 충돌 위험(JSON 파일 저장).
4. **워크플로우 부재**: 개정 요청→검토→승인 단계 상태관리 없음(등록만), 시정조치(8D)·부적합·고객불만·4M 변경·교육·계측기·설비·금형·협력사 평가 등 **운영 모듈이 전부 엑셀 대장**에 머묾.
5. **KPI 수기 입력**: 원천 데이터(생산·불량)와 미연결, 미달 시 대책 연결(개선활동 등록) 기능 없음, 목표 [확인필요] 17건 방치.
6. **알림/할 일 엔진 없음**: 캘린더가 주기 리스트일 뿐, 도래·기한초과·미작성 알림 없음. 유효성 확인(1개월 후) 추적 불가.
7. **ISO 조항 커버리지 공백**: 9.3 경영검토(입력·출력·지시사항 추적 화면 없음), 6.1 리스크·기회 대장, 4.1/4.2 이해관계자·이슈, 7.1.5 모니터링·측정자원(계측기 교정), 7.2 역량/교육훈련 이력, 8.4 외부공급자 평가, 8.5.6 변경관리, 8.7 부적합 출력물, 10.2 시정조치, 9.1.2 고객만족 — 모두 문서만 있고 시스템 기능 없음. (MES 사례는 이 중 상당 부분을 기록 화면으로 보완)
8. 사진·첨부 증빙, QR 현장 접근, 다국어(SQ 1_3 외국인 작업자) 미지원.

### 7-2. 개선 제안 — 차별화 포인트 (포털 대비 우위 확보)
1. **개인 계정 + 역할 기반 권한(RBAC)** (작성자/검토자/승인자/심사원/관리자/열람), 모든 변경 **감사로그**.
2. **전자결재 워크플로우**: 문서 제·개정(요청→초안→검토→승인→배포→구본 회수, 상태값), 기록 결재(작성/검토/승인 = 양식 결재란을 전자서명으로), 반려·코멘트.
3. **양식의 전자기록화(이행실적 DB화)**: 우선 착수 12종부터 웹/모바일 입력 폼(실측값·판정기준 자동 합부), 보존기간 자동관리, **3개월 연속 기록 충족도**를 SQ 항목별로 자동 표시 → SQ 이행실적 점수 근거.
4. **캘린더 → 실제 할 일 엔진**: 주기 기반 자동 과제 생성, 미작성/기한초과 알림(웹 푸시·카카오/메일), 부서별 이행률 대시보드.
5. **부적합·시정조치(8D)·고객불만 모듈**: 발생→원인→대책→유효성 1·2·3개월 추적, 지연일 표시, 내부심사 지적사항 자동 연계(MES 사례 수준).
6. **4M 변경 / 금형(타발수·세척 도래) / 설비 일상점검(OK/NG) / 계측기 검교정·MSA / 원재료 유효기간·숙성** 모듈 — MES 사례 기능을 MST 업종에 맞게 선택 반영.
7. **경영검토 모듈**(9.3.2 입력 자동 수집 — KPI·심사결과·고객만족·부적합·공급자 성과 → 지시사항 등록·완료 추적), **리스크·기회 대장**, 이해관계자·SWOT, 교육훈련/자격 이력, 협력사 평가.
8. **KPI 자동 산출**: 기록 데이터(검사·불량·납품)에서 PPM·불량률 자동 계산, 미달 시 개선과제 자동 생성, [확인필요] 목표 플래그.
9. **현장 친화 기능**: QR(설비·금형·문서 게시물에 부착 → 최신본/점검폼 바로 열기), 바코드/LOT 스캔, **사진 업로드(증빙·부적합)**, 모바일 반응형/PWA·오프라인 임시저장, 다국어(외국인 작업자, SQ 1_3).
10. **인프라**: 클라우드(예: 네이버 클라우드) 또는 관리형 서버 + **자동 백업·복구**, HTTPS, 외부 접속 통제(사내망/VPN 옵션), 동시 사용 안전한 DB.
11. **심사 대응 모드**: 조항/SQ 항목 선택 → 근거 문서 + 최근 기록 + 지적 이력을 한 화면/한 PDF 패키지로 출력(MES 사례의 "문서와 MES가 이어진 곳" 개념).
12. 엑셀 일괄 가져오기/내보내기(문서체계표·양식마스터·KPI·체크시트 구조 그대로) — 컨설팅 산출물에서 바로 초기 데이터 적재.
